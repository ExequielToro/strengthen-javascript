# Strengthen JavaScript 💻💪

[![Made with JavaScript](https://img.shields.io/badge/Made%20with-JavaScript-yellow)](https://www.javascript.com/)

Este repositorio contiene mis **prácticas y mini proyectos en JavaScript**, organizados por temas, con el objetivo de fortalecer mis habilidades, aplicar buenas prácticas y llevar un registro de mi aprendizaje.

## 🗂 Estructura del repositorio

- `01-variables/` → ejercicios básicos de variables.  
- `02-funciones/` → prácticas de funciones y su uso.  
- `03-arrays/` → ejercicios de arrays y métodos relacionados.  
- Se irán agregando más carpetas según avance con temas como objetos, DOM, eventos y más.

## 🎯 Objetivo

- Mantener un registro organizado de mi progreso en JavaScript.  
- Practicar con ejemplos reales y mini proyectos.  
- Aplicar buenas prácticas de GitHub y control de versiones.
